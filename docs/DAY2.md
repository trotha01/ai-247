# Day 2: fake-live Worker (`worker/`)

A Cloudflare Worker that turns `manifest.json` (in R2) plus the clock into a rolling live HLS media playlist. Nothing here is deployed.

## Endpoints

| Path | Behaviour |
|---|---|
| `/live.m3u8` (alias `/index.m3u8`) | Rolling playlist, 5 segments (30 s) ending at the live edge. `cache-control: public, max-age=1`. |
| `/seg/<key>.ts` | Streams the R2 object `PREFIX + key`; immutable cache. Only `[A-Za-z0-9_.-/]+.ts`, no `..`. |
| `/healthz` | JSON: which source is on air (`live-manifest` / `replay-pool`), manifest age, pool state (see `docs/FAILOVER.md`). Always 200. |

CORS is `*` (hls.js on Pages is a different origin). If `manifest.json` is missing, empty, stale or points at missing segments the Worker serves the replay pool (`pool/manifest.json`, see `docs/FAILOVER.md`); 503 only when there is neither.

## Algorithm (port of `newsbot/playlist.py: channel_playlist`, golden-tested against it)

- `live = floor((now - epoch) / segment_seconds)`; `epoch` = manifest `epoch` field, else the `EPOCH` var (fixed in `wrangler.toml`).
- Global segment `k` plays `cycle[k % N]`. `EXT-X-MEDIA-SEQUENCE` = `k` of the first listed segment, so it only ever increases, including across loops.
- Every block start (and the wrap to block 0) gets `EXT-X-DISCONTINUITY`; `EXT-X-DISCONTINUITY-SEQUENCE` counts tagged segments that left the window.
- Manifest shapes accepted: Day 0 `{segments:[{file,duration}]}` (one block) or `{blocks:[{id,segments:[{uri,duration}]}]}` (bulletin, slate, replays; same layout as Day 1 `pool.channel_blocks`). Segment URIs are resolved as `seg/<uri>`, i.e. R2 key `PREFIX + uri`.
- Manifest is cached in the isolate for 10 s.

## Manifest change mid-stream (resolved: see `docs/MANIFEST-SWAP.md`)

Below is the original limitation; the epoch/`cycle_start_k`/`cycle_start_dseq`/`prev` scheme now covers it.


`k % N` is recomputed from whatever manifest is current. When Day 1 uploads a new hourly manifest (different N or contents), the segment behind a given media-sequence number can change for clients that have it cached, and the discontinuity-sequence count restarts from the new layout. hls.js recovers (reloads, may stall a few seconds) but it is not seamless. Fix options for Day 3: publish manifests with an `epoch` and a `cycle_start_k` so the swap happens only at a loop boundary, or have the generator emit the new manifest with `epoch` shifted to keep `k` continuous. Not done here to stay inside the Day 2 scope.

## Tests

```
cd worker && npm ci && npm test        # 48 tests, ~30 s
npm run test:unit                      # pure logic only, <1 s
```

- `test/unit`: playlist invariants (43), validated with `hls-parser`: sequences never decrease over 600 reloads / many loops, same absolute number maps to same URI, discontinuity-sequence arithmetic, wrap tagging, and byte-for-byte equality with golden output generated by the Python reference (`test/fixtures/python-golden.json`).
- `test/dev`: starts `wrangler dev --local` (workerd + Miniflare R2), seeds local R2 with the fixture, and checks the HTTP surface (playlist, segments, headers, 400/404/405). A test-only `now` query param is honoured only when the var `ALLOW_TIME_OVERRIDE=1` is passed on the command line (not in `wrangler.toml`).
- Reused tools: `wrangler`/Miniflare, `hls-parser`, `vitest`. No custom HLS parsing.

### Fixture caveat

The brief asked for artifact `bulletin-day0` (run 42187611180). Listing it works, but downloading is blocked from the cloud session (the artifact blob host `productionresultssa4.blob.core.windows.net` is refused by the egress proxy). `worker/test/fixtures/bulletin-day0/manifest.json` is therefore a schema-faithful reconstruction of what `newsbot/manifest.py:build_manifest` writes (version, segment_seconds=6, 10 segments with index/file/duration/audio_duration/container_duration/bytes/sha256/scene, sources). Segment payloads are dummy bytes written at test time (`*.ts` is gitignored). The Worker only reads `file` and `duration`. To check against the real artifact: download it, replace the fixture `manifest.json`, rerun `npm test`.
